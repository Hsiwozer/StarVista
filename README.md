# StarVista

**StarVista** 是一个沉浸式天文主题网站，围绕星空视觉、深空影像、天文科普与观星体验展开。

## 在线预览 / Website Demo

网站已部署在 Netlify，可以直接访问：

**https://starvista.netlify.app/**

打开链接即可进入 StarVista，体验首页星空视觉、每日星讯、深空展厅、宇宙档案和观测手册等页面内容。

## 项目简介

StarVista 希望把天文内容做成一座可以浏览、停留和探索的「宇宙档案馆」。整体设计偏沉浸式与神秘感，使用深色星空背景、深空影像、柔和光晕、玻璃质感和克制的动效，营造接近夜空观测与宇宙档案浏览的体验。

项目内容结合天文科普、视觉展示与观星入门：既可以快速浏览每日星讯和深空影像，也可以阅读围绕太阳系、恒星、星云、星系、黑洞等主题整理的天文文章。

## 主要功能

- **首页沉浸式星空视觉**：以星空、星云和深色宇宙氛围作为第一视觉入口。
- **星空图库 / 深空影像展示**：展示星云、星系、月球、行星、黑洞等主题影像，并支持按分类浏览。
- **每日星讯模块**：每日呈现一幅深空影像与对应的档案信息。
- **天文文章**：整理适合公开浏览的天文科普内容，覆盖多个宇宙主题。
- **观星指南**：提供从光污染、星座识别到设备选择的观星入门建议。
- **宇宙展厅**：以展厅式布局组织深空图像与宇宙档案内容。
- **响应式页面设计**：适配桌面端与移动端浏览，保持清晰的阅读和探索体验。

## 页面模块介绍

- **Hero / 星空入口**：网站首屏，承担 StarVista 的视觉定调与主要导航入口。
- **Daily Signal / 每日星讯**：根据日期展示每日深空主题内容，包含影像、标题、分类与来源入口。
- **Deep Space Gallery / 深空展厅**：集中展示深空影像，适合按主题快速浏览宇宙视觉内容。
- **Cosmic Archives / 宇宙档案**：天文文章区域，用卡片形式呈现不同宇宙主题的科普内容。
- **Observer's Manual / 观测手册**：面向初学者的观星指南，帮助用户理解如何开始观察夜空。
- **Prologue / Star Archive**：补充项目气质与创作愿景，强化「宇宙档案馆」的世界观。

## Tech Stack

- **React**：构建页面组件与交互结构
- **TypeScript**：提供类型约束，让内容数据与组件使用更稳定
- **Vite**：负责本地开发与生产构建
- **Tailwind CSS**：组织响应式布局、视觉样式与页面氛围
- **Lucide React**：提供轻量图标
- **Netlify**：承载线上部署与公开访问

## 本地运行方式

确保本地已安装 Node.js 与 npm，然后在项目根目录执行：

```bash
npm install
npm run dev
```

终端会输出本地预览地址，通常类似：

```text
http://localhost:5173/
```

构建生产版本：

```bash
npm run build
```

本地预览构建结果：

```bash
npm run preview
```
